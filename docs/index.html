Wedding Slideshow

Run the photo upload service and browser-based slideshow on Kubernetes with shared persistent storage.

View on GitHub Repository index

Install

Add the repository and install the chart into its own namespace.

helm repo add wedding-slideshow https://luth2.github.io/WeddingSlideshow
helm repo update
helm upgrade --install wedding-slideshow wedding-slideshow/wedding-slideshow \
  --namespace wedding-photos \
  --create-namespace

Configure

Set the event title, storage class, service types, image tags, and resource limits in a values file.

slideshow:
  config:
    title: Our Wedding
    intervalSeconds: 8

persistence:
  storageClass: azurefile-csi
  size: 20Gi

Apply it with --values values.yaml. An existing PVC can be selected with persistence.existingClaim.
